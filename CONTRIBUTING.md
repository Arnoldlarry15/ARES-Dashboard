# Contributing to ARES Dashboard

Thank you for your interest in contributing to ARES Dashboard!

Please see the complete contributor guide in [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md) for:
- Development environment setup (PostgreSQL + `pgvector`, Prisma migrations, worker, and tests)
- Coding standards, TypeScript, and ESLint checks
- Pull request process and security review expectations

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).
